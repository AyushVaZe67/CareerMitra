# 🎯 Career Role Classification Android App

An Android-based ML system that predicts suitable **career roles** for users based on their skills and preferences.

---

## 🧠 Overview

* Built using **Supervised Learning** for accurate career classification.
* Uses a **dynamic questionnaire** to capture user data and form skill-based feature vectors.
* Delivers **personalized career recommendations** through a predictive analytics pipeline.

---

## ⚙️ Tech Stack

* **Frontend:** Java, XML (Android Studio)
* **Backend:** Flask (Python)
* **ML:** Scikit-learn, Pandas, NumPy
* **Model Type:** Supervised Learning Classifier

---

## 🚀 Workflow

1. User completes a dynamic skill questionnaire.
2. Data converted into feature vectors.
3. ML model predicts the best-fit career roles.
4. Android app displays personalized recommendations.
